Vamos começar pela entidade `User`, que será essencial para a futura autenticação com Spring Security.

Crie o arquivo:

`src/main/java/com/julyturadm/domain/repository/UserRepository.java`

```

package com.julyturadm.domain.repository;

import com.julyturadm.domain.entity.User;
import org.springframework.data.jpa.repository.JpaRepository;

import java.util.List;
import java.util.Optional;

public interface UserRepository extends JpaRepository<User, Long> {

    Optional<User> findByEmail(String email);

    boolean existsByEmail(String email);

    List<User> findAllByEnabledTrue();
}

```

Por que essas consultas?

| Método                 | Finalidade                                |
| ---------------------- | ----------------------------------------- |
| `findByEmail`          | Localizar a conta para autenticação.      |
| `existsByEmail`        | Verificar se o e-mail já está cadastrado. |
| `findAllByEnabledTrue` | Listar somente usuários habilitados.      |
| `findById`             | Já fornecido pelo `JpaRepository`.        |
| `save`                 | Já fornecido pelo `JpaRepository`.        |
| `findAll`              | Já fornecido pelo `JpaRepository`.        |

Atenção: os métodos derivados exigem que a entidade `User` tenha os atributos Java `email` e `enabled`.

Antes de avançarmos, precisamos confirmar os nomes e tipos reais desses atributos no seu código.

Não vamos alterar a entidade nem o banco para acomodar uma suposição.
