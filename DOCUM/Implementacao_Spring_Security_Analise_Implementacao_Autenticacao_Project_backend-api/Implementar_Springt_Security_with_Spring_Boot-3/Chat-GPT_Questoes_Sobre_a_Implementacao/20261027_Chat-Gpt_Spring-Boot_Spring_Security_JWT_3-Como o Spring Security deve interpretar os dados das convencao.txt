Por exemplo:

O método acima é apenas ilustrativo.
Em uma implementação real, ele deverá receber os dados de atualização, validar o recurso e executar
a operação na camada de serviço.

A autorização deverá ser negada se o usuário não tiver a autoridade exigida, mesmo que esteja autenticado.


2. Uma regra essencial para o carregamento.

A associação com um perfil não concede, por si só, todas as permissões possíveis do módulo.

O que será carregado dependerá dos registros existentes em `roles_permissions`.

Da mesma forma, a aplicação precisa buscar as permissões de todos os perfis atribuídos ao usuário,
e não apenas o primeiro perfil encontrado.

Isso evita que um colaborador com dois perfis tenha parte de suas permissões ignorada.
